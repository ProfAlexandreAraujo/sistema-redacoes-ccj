# AUDITORIA DO SISTEMA — CCJ CMRJ
### versão 2026-05-25 rev.11

## 1. Contexto
Sistema Streamlit auxiliar da CCJ/CMRJ para Redação Final de PLs aprovados com emendas
(art. 250, Res. 1.673/2025 RI).

Constraint absoluta: "Eu não posso mexer no teor da emenda."
Permitidas apenas: (a) atualização de referências cruzadas por renumeração (A2);
                   (b) correções de linguagem sem alteração de significado jurídico (E1).

## 2. Normas: LC 95/1998 · Decreto 12.002/2024 · LC Municipal 48/2000 · LC 51/2001 · Res. 1.673/2025 art. 250

## 3. Três níveis de alerta

⚠️ §1º RI — Aviso Redacional: erro de linguagem que não deturpa vontade legislativa.
   → Erros de ortografia/concordância/pontuação: corrigidos automaticamente + LOG + AVISOS.

🚨 §2º RI — Erro Crítico: contradição entre emendas aprovadas.
   → Providência regimental: reabertura da discussão.
   → DOCX: RASCUNHO DE TRABALHO por padrão; relator pode confirmar → REDAÇÃO FINAL +
     ALERTA CRÍTICO + log OVERRIDE-HUMANO.

🔴 §2º RI — Absurdo Manifesto: ininteligibilidade formal.
   → Texto preservado verbatim + marcador inline (removido do DOCX).
   → Providência: reabertura. NUNCA correção por ofício do §1º.

Sistema de dois modos:
  RASCUNHO: §2º sem confirmação → título "RASCUNHO DE TRABALHO — NÃO É REDAÇÃO FINAL",
            sem sufixo -A, cabeçalho vermelho.
  REDAÇÃO FINAL: §2º com confirmação → título "REDAÇÃO FINAL", sufixo -A,
                 "ALERTA CRÍTICO PENDENTE" no cabeçalho, OVERRIDE-HUMANO no log.

## 4. Regras do sistema

A1 — Preservação de teor (REGRA ABSOLUTA): incorporar emenda LITERALMENTE.
     Única exceção: E1 (linguagem sem alteração de significado).

A2 — Referências cruzadas: única intervenção automática de conteúdo.
     Especial aglutinativas: conteúdo de art. Y migrado para art. X → refs ao conteúdo de Y → art. X.

E1 — Correções automáticas + LOG + AVISOS:
     Corrija: concordância nominal/verbal; caixa de palavras comuns; pontuação de incisos.
     NUNCA altere: números, valores, prazos, percentuais, termos técnicos, sujeito/objeto/verbo.
     APONTE (sem corrigir): "anterior"/"seguinte" sem especificação; "parágrafo único" incorreto;
                           ausência de "; e" (LC 48/2000 — prática legislativa ignora).

E1.5 — NUNCA em AVISOS: mérito, CA, gabaritos, parâmetros urbanísticos (soberania do Plenário).

E2 — Erros Críticos (§2º): contradição entre emendas. Nunca resolve.

E3 — Absurdo Manifesto (§2º): 4 casos obrigatórios:
     (1) autoreferência circular; (2) condição → § suprimido;
     (3) "artigo anterior" materialmente incompatível; (4) ref. exclusiva a dispositivo suprimido.

P1 — Pós-processador Python (camada independente do modelo):
     Caso 1: Art. N com ref. preposicionada ao próprio Art. N → autoreferência circular.
     Caso 2: §N com "§N deste artigo" → condição normativa inoperante.
     Caso 3: padrões semânticos nos textos dos avisos.
     Qualquer item escalado: move de avisos → alertas_absurdos.

def parsear_emendas_com_ia(texto_emendas: str, api_key: str) -> list[Emenda]:
    """
    Usa Claude para identificar e estruturar emendas a partir de um texto bruto.
    Divide em lotes se o texto for muito longo.
    """
    client = anthropic.Anthropic(api_key=api_key)
    chunks = _chunk_text(texto_emendas, max_chars=60_000)
    todas_emendas: list[Emenda] = []
    offset = 0

    for chunk in chunks:
        prompt = f"""Você é especialista em técnica legislativa municipal brasileira.
Analise o texto abaixo contendo emendas a um projeto de lei da CMRJ.
Extraia CADA emenda em formato JSON.
Para cada emenda: numero, tipo (Modificativa|Supressiva|Aditiva|Substitutiva|Aglutinativa|Outro),
alvo (dispositivo), novo_texto (null para Supressiva), texto_bruto (integral, EXATAMENTE),
autor, notas.
Responda SOMENTE com JSON: {{"emendas": [...]}}
TEXTO DAS EMENDAS:
{chunk}"""

        n_antes = len(todas_emendas)

        try:
            with client.messages.stream(
                model="claude-sonnet-4-6",
                max_tokens=20000,
                messages=[{"role": "user", "content": prompt}]
            ) as stream:
                resp_text = stream.get_final_text()

            # Extrai JSON da resposta
            match = re.search(r'\{.*\}', resp_text, re.DOTALL)
            if not match:
                raise ValueError(
                    "IA não retornou JSON válido neste lote — "
                    "emendas serão criadas como brutas para revisão manual."
                )
            data = json.loads(match.group())

            for idx_item, item in enumerate(data.get("emendas", []), start=1):
                tipo_map = {t.value: t for t in TipoEmenda}
                texto_bruto = (
                    item.get("texto_bruto")
                    or item.get("novo_texto")
                    or f"[Emenda {item.get('numero', '?')} — {item.get('tipo', '')} | {item.get('alvo', '')}]"
                )
                numero = item.get("numero")
                if numero is None:
                    numero = offset + idx_item
                e = Emenda(
                    numero      = numero,
                    texto_bruto = texto_bruto,
                    tipo        = tipo_map.get(item.get("tipo") or "", TipoEmenda.OUTRO),
                    alvo        = item.get("alvo"),
                    novo_texto  = item.get("novo_texto"),
                    autor       = item.get("autor"),
                    parseada    = True,
                    notas_parse = item.get("notas"),
                )
                todas_emendas.append(e)

        except (json.JSONDecodeError, KeyError, IndexError, ValueError):
            # Se parsing falhar (JSON malformado OU sem JSON), cria emendas brutas
            partes = re.split(r'\n(?=EMENDA\s)', chunk, flags=re.IGNORECASE)
            for parte in partes:
                if parte.strip():
                    num = offset + len(todas_emendas) + 1
                    todas_emendas.append(Emenda(
                        numero=num, texto_bruto=parte.strip(), parseada=False,
                        notas_parse="Parsing automático falhou — revisar manualmente"
                    ))

        offset += len(todas_emendas) - n_antes

    todas_emendas.sort(key=lambda e: e.numero)
    return todas_emendas
